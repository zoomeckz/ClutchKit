ClutchKit 3.0 - stream toolkit for TikTok LIVE Studio
======================================================
Counters for anything you want to track (deaths, wins, kills, attempts...), each with
its own hotkeys, shown live on stream with your own font, colors and animations.
Gift actions: when a viewer sends a gift, ClutchKit presses keys in your game.


INSTALL
-------
1. Unzip this folder and double-click ClutchKit.exe.

2. If Windows shows "Windows protected your PC":
   click "More info", then "Run anyway".
   (Windows shows this for small apps that aren't code-signed yet.)

3. Click "Install". ClutchKit opens and adds itself to the Start menu
   (and the desktop, if you leave that box ticked). No admin rights needed.

   Prefer not to install? Click "Run without installing" - ClutchKit then
   keeps its files next to ClutchKit.exe.


ADD IT TO TIKTOK LIVE STUDIO
----------------------------
In ClutchKit, open "Display":

  Link overlay (recommended, see-through):
    1. Click "Copy LIVE Studio link".
    2. In LIVE Studio: Add source > Link > paste (Ctrl+V) > Add source.
    3. Resize and place it. You only do this once - changes you make in
       ClutchKit show up on stream automatically, and it doesn't matter
       whether you start LIVE Studio or ClutchKit first.

  Capture window:
    Pick "Capture window", then in LIVE Studio: Add source > Window capture >
    "ClutchKit - Overlay". Keep that window open (it can sit behind your
    game, just don't minimize it).


USING IT
--------
The first counter is "Deaths" with these keys:
  Numpad +   add one
  Numpad -   remove one
  Numpad *   reset to 0

On the "Counters" page you can rename it, add more counters (up to 8) and give
each one its own keys: click a key button, then press the key you want.
The keys keep working while you're in a game, and your game still gets the key press.

Closing the window keeps ClutchKit running by the clock (red icon with three lines).
Double-click the icon to open it again, right-click it to exit.


GIFT ACTIONS (GIFTS PRESS KEYS IN YOUR GAME)
--------------------------------------------
1. Get a free Euler Stream API key: on the "TikTok LIVE" page click
   "Get a free key", make an account and copy your API key.
   (TikTok has no official way to read LIVE gifts; Euler Stream does it for you.)
2. On the "TikTok LIVE" page, type your TikTok username, paste the key and
   click "Connect". Tick "Connect automatically" so you never have to do it again.
   If you aren't live yet, ClutchKit waits and connects when you go live.
3. On the "Gift actions" page click "+ Add gift action":
     Gift        the gift's name, e.g. Rose (several: Rose, GG). Empty = any gift.
     min. coins  only gifts worth at least this much (e.g. 100 for big gifts).
     Press a key the key to press in your game, and how long to hold it.
     Type text   types text, e.g. a Minecraft command. "First" = a key pressed
                 before typing (T opens the chat in Minecraft).
     Times       how many times per gift.
     For every gift in a combo: a x10 Rose combo runs it 10 times
                 (untick: once per combo).
4. Use "Test in 3 s" (or "Test with a fake gift"), click into your game and watch.

Tips:
- "Only press keys in": pick your game, so gifts never type into chat or Discord.
- Set an "On/off key" to stop gift actions instantly, e.g. while you're in a menu.
- If your game runs as administrator, Windows blocks keys from normal programs.
  ClutchKit tells you, and "Restart as administrator" fixes it.
- Games with strict anti-cheat (e.g. Valorant, Fortnite) may ignore pressed keys.


UNINSTALL
---------
Windows Settings > Apps > Installed apps > ClutchKit > Uninstall.


PRIVACY
-------
The LIVE Studio overlay talks to ClutchKit on your own PC only (127.0.0.1).
The keyboard is only used to react to your chosen hotkeys; nothing you type is stored.
The only internet connection is the TikTok LIVE connection, and only when you
connect: your TikTok username and Euler Stream key go to Euler Stream, which
sends back your LIVE's gifts. The key is saved in settings.ini on your PC.
